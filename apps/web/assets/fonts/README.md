# Open Graph image fonts

Static WOFF files for `src/app/opengraph-image.tsx`. The OG renderer can't use `next/font` or
variable fonts, so it reads these directly. Both are SIL Open Font License 1.1 (licenses alongside).

| File | Font | Source |
| --- | --- | --- |
| `fraunces-latin-400-normal.woff` | Fraunces 400, Latin | Fontsource (`@fontsource/fraunces`) |
| `geist-latin-400-normal.woff` | Geist 400, Latin | Fontsource (`@fontsource/geist-sans`) |
